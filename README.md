## 🚀 TaskFlow - Smart Task Management System

TaskFlow is a modern full-stack task management application built using **Java, Spring Boot, React, and MySQL**.

The goal of this project is to help users organize tasks, track progress, manage priorities, and collaborate efficiently through a clean and responsive interface.

> 🚧 This project is currently under active development.

# ✅ Backend Features Implemented

### User Management
- User Registration API
- Get All Users
- Get User by ID
- Update User
- Delete User

### Backend Architecture
- Layered Architecture (Controller, Service, Repository)
- DTO Pattern
- Spring Data JPA
- Hibernate ORM

### Validation & Error Handling
- Request Validation using Jakarta Validation
- Global Exception Handling
- Custom Validation Responses

### Security
- Password Encryption using BCrypt
- Basic Spring Security Configuration

### Database
- MySQL Integration
- Automatic Entity Mapping using Hibernate

# ▶️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/dharna27/taskflow-task-management-system.git
```

### Backend

1. Configure MySQL in `application.properties`.
2. Create a database named:

```
taskflow
```

3. Run the Spring Boot application.

The backend will start on:

```
http://localhost:8080
```
